# Reali Mobile

Configure a API em `.env.local` usando `.env.example` como referência. Instale com `npm ci` e execute `npm start` com a API Django acessível ao dispositivo.

[Arquitetura](docs/MOBILE_ARCHITECTURE.md) · [Integração das telas](docs/MOBILE_SCREEN_INTEGRATION.md) · [Android e iOS](docs/MOBILE_ANDROID_IOS.md) · [Testes](docs/MOBILE_TESTS.md) · [Relatório da Fase 8](docs/PHASE8_REPORT.md)

O sino nas telas iniciais abre a central de notificações da escola selecionada. Para push, use um build Android/iOS configurado, ative a inscrição do dispositivo e escolha os tipos na tela de preferências. [Configuração nativa e de entrega](../backend/docs/NOTIFICATIONS_PUSH.md)
